# Work with Release Readiness

If you downloaded this repository from GitHub, unzip it and use its `agent` folder. If you have the separate Release Readiness download, unzip that folder. Keep its files together.

Open the agent folder as a local project in Codex or in the Code tab of Claude Desktop. Say **Set me up**.

The agent will ask about your support operation, learn the launch rules and save the context. Then give it a product plan and say **Start a release**. You can return later with an updated plan, a colleague's reply or a question about what still needs attention.

You need the desktop app, a company-approved account and permission for a private working folder. There is no Python or Node installation. The app may ask you to allow file access and the agent's built-in macOS helper; the agent explains what it is saving.

Company work stays outside this download, in your local Application Support folder. Keep active records local. Share the generated brief and action list with colleagues, then bring their replies back to the agent. One person updates the working record at a time.

To update the agent, close its old session and replace this downloaded folder. Keep the private working folder. Open the new agent and say **Continue my release**. Do not delete your working records or run two copies as concurrent writers.

This build targets macOS local sessions in both apps. Desktop setup and independent support-lead use still need their acceptance checks; the build evidence records what has actually been tested. No helpdesk connections or background monitoring are included. The lead owns the launch decision and any messages or customer actions.
